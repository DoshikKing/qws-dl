# Project skills

`design-taste-frontend` is Taste Skill v2.1.5 from
https://github.com/Leonxlnx/taste-skill, pinned to upstream commit
`12af471f627f866411b4bd785b19646d3672784c`.

Installed in `.agents/skills/` for Codex project discovery. Start a new Codex
session in this repository to load newly installed skills. Requires Node 22+
and Chrome, Edge or Chromium for browser inspection. No npm packages or API
keys are required. See the bundled `LICENSE` for the upstream MIT license.
