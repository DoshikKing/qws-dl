# QWS · OrpheusDL Web

[English — основной README](README.md) · [Подробная документация](INFO.ru.md)

Веб-интерфейс на Nuxt для OrpheusDL и его модуля Qobuz: очередь ссылок,
выбор качества, журнал, отмена заданий, скачивание отдельных файлов и ZIP-архивов.
Регистрация доступна по приглашению. У пользователей есть личные коды; администратор управляет аккаунтами.
Срок хранения выбирается для каждого задания: **от 1 до 24 часов**.
После его окончания файлы и архив автоматически удаляются.

## Дисклеймер

QWS — **неофициальный веб-интерфейс и средство запуска стороннего ПО**.
Проект не предоставляет самостоятельного прямого доступа к скачиванию треков Qobuz,
не выдаёт аккаунты или подписки, не предоставляет права на контент и не обходит ограничения доступа.
Авторизация и обработка медиа зависят от OrpheusDL, его модулей и перечисленных ниже библиотек.
Используйте собственный подходящий аккаунт и скачивайте только контент, к которому у вас есть разрешённый доступ.
Проект не связан с Qobuz и не одобрен Qobuz или разработчиками сторонних компонентов.

## Быстрый запуск

```sh
cp .env.example .env
# Заполните ADMIN_USERNAME, ADMIN_PASSWORD, QOBUZ_USERNAME и QOBUZ_PASSWORD.
docker compose up -d --build
```

Откройте порт `3000` на локальном хосте и выберите «Войти», затем используйте `ADMIN_USERNAME` / `ADMIN_PASSWORD`.
Веб-вход включён по умолчанию: вручную искать `app_id` / `app_secret` не нужно.
Для запуска под `/dl/` задайте `NUXT_APP_BASE_URL=/dl/` и используйте
[блоки nginx](deploy/nginx-dl.conf).

Все настройки, хранение и удаление файлов, разработка, проверки и ограничения
описаны в **[INFO.ru.md](INFO.ru.md)**. [English documentation](INFO.md).
